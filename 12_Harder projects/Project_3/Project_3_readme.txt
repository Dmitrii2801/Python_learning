Программа позволяет пользователю вводить коэффициенты квадратичной функции вида y = a*x^2 + b*x + c и строить их графики на одном поле.

1. Пользователь вводит коэффициенты a, b, c через запятую (например, 1, -2, 1). Ввод продолжается, пока пользователь не введёт пустую строку.

2. Внешняя функция parse_coefficients(line) принимает строку, разбивает её на части, пытается преобразовать каждую в число с плавающей точкой.
Если количество частей не равно 3 или хотя бы одно преобразование не удалось, функция возвращает None. В противном случае возвращает кортеж (a, b, c).

3. Все корректные наборы коэффициентов сохраняются в список кортежей.

4. После завершения ввода программа с помощью numpy создаёт массив x от -10 до 10 с шагом 0.1 и для каждого набора коэффициентов вычисляет y = a*x^2 + b*x + c.

5. С помощью matplotlib строит все кривые на одном графике (с разными цветами). Добавляет легенду с подписями вида y = a*x^2 + b*x + c.

6. Обработка исключений:

6.1 при разборе строки (преобразование в float),

6.2 при проверке количества аргументов,

6.3 если список коэффициентов пуст — выводится сообщение и график не строится.

7. Предусмотрите случай, когда пользователь вводит коэффициенты, но a = 0 — это допустимо (получится линейная функция), программа должна корректно
строить и её.
