Написать программу, которая позволяет пользователю вводить данные об успеваемости студентов. Каждая запись содержит имя студента и
его оценку (число с плавающей точкой) через пробел. Ввод продолжается до тех пор, пока не будет введена пустая строка.

Программа должна:

1. С помощью внешней функции parse_record(line) разбирать введенную строку: разделять ее на имя и оценку, преобразовывать оценку в float.
Если строка не содержит ровно двух частей или оценка не является числом, функция возвращает None, а программа выводит сообщение об ошибке
и запрашивает ввод заново (или пропускает запись).

2. Все корректные записи сохранять в список кортежей вида (имя, оценка).

3. После завершения ввода, если список не пуст, создать pandas.DataFrame с колонками "Имя" и "Оценка".

4. С помощью pandas и numpy вычислить и вывести в консоль:

4.1 количество студентов,

4.2 среднюю оценку,

4.3 медиану,

4.4 стандартное отклонение,

4.5 максимальную и минимальную оценки.

5. С помощью matplotlib построить гистограмму распределения оценок (количество интервалов выбрать автоматически или задать,
например, 5–10 столбцов). Добавить заголовок, подписи осей и сетку.

6. Предусмотреть обработку исключений:

6.1 при преобразовании строки в число (внутри parse_record),

6.2 при попытке создания DataFrame из пустого списка (выводить сообщение и не строить график),

6.3 при других возможных ошибках (например, при вводе нечисловой оценки).
