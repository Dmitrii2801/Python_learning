Напишите программу, которая позволяет пользователю вводить значения температур (в градусах Цельсия) за несколько дней. Программа должна:

1. Запрашивать у пользователя температуру для каждого дня. Ввод продолжается, пока пользователь не введёт пустую строку.

2. С помощью внешней функции validate_temperature(value) пытаться преобразовать введённую строку в число с плавающей точкой.
Если преобразование невозможно (например, буквы), функция возвращает None, а программа выводит сообщение об ошибке и просит ввести
значение заново для текущего дня.

3. Все корректно введённые температуры сохранять в список.

4. После завершения ввода программа с помощью numpy вычисляет:

4.1 среднюю температуру,

4.2 максимальную и минимальную температуру,

4.3 стандартное отклонение.

5. С помощью matplotlib строит два графика (в одном окне, но на разных подграфиках или на одном):

5.1 линейный график изменения температуры по дням (ось X — номер дня),

5.2 гистограмму распределения температур (чтобы визуализировать частоту).

6. Обработка исключений должна присутствовать при преобразовании строки в число (в функции валидации) и
при использовании numpy (если список пуст — выводить сообщение и не строить графики).

Требования к реализации:

1. Все математические расчёты выполнять с помощью numpy (например, np.mean, np.std).

2. Для построения графиков использовать matplotlib.pyplot.

3. Внешняя функция validate_temperature обязана быть определена вне основного блока.

4. Использовать цикл while для ввода.

5. Список для хранения температур.
