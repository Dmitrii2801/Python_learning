# Python_learning
Изучение языка программирования Python

# Папки внутри репозитория Python_learning
1. 1_Simple projects: изучение типов данных и переменных; применение простейших арифметических действий; операции ввода input() и вывода print() данных; простейших библиотек Python (import random); преобразование типов данных

2. 2_If else projects: применение условного оператора if() к задачам различной сложности

3. 3_Cycles: применение циклов for() и while() к задачам различной сложности; развитие задач с переменными и списками

4. 4_Operations and methods for str: применение методов для работы со строками (конкатенация строк, проверка наличия конкретного элемента в переменной или списке, форматирование строк)

5. 5_Lists: изучение списков (тип данных list); применение списков к задачам различной сложности

6. 6_Dictionaries: изучение словарей (тип данных dict); применение словарей к задачам различной сложности

7. 7_Tuple and sets: изучение кортежей (тип данных tuple) и множеств (тип данных set); применение кортежей и множеств к задачам различной сложности

8. 8_Functions: изучение реализации функций различной сложности; развитие задач из предыдущих папок

9. 9_Files: изучение работы с файлами; чтение данных из файла, запись данных в файл
